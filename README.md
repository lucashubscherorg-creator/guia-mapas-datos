# guia-mapas-datos

Datos de base para la *Guía de mapas de contingencia de la República Argentina* (autor: LH).

La tarea automática `OSM Argentina (Geofabrik)` descarga el extracto de Argentina de
[Geofabrik](https://download.geofabrik.de/south-america/argentina.html), verifica su MD5 y lo publica
en **Releases** (`osm-AAMMDD`).

Datos: © colaboradores de OpenStreetMap, disponibles bajo la licencia ODbL.
